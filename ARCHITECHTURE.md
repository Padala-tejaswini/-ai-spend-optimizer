Data Flow
User Input

Visitor enters subscription details (tools, plan, spend, team size, use case).

Audit Engine

Backend applies rules:

Detect duplicate tools.

Identify oversized plans.

Flag unused features.

Calculates potential monthly + annual savings.

Results Rendering

Instant results shown on the frontend.

Clear breakdown of overspending + recommendations.

Report Capture

User can export the audit report.

Email capture triggered only after results are displayed.

Consultation Funnel

If savings exceed threshold (e.g., >$200/month), option to book a Credex consultation.

Shareable Report

Each audit generates a unique public URL.

Open Graph metadata ensures proper previews on Twitter, LinkedIn, Hacker News.
